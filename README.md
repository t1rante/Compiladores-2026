# My Basic Calculator

## Como funciona?
- Implementação de um parser e um lexer em C para uma calculadora de funções básicas, atribuição de variáveis e expressões separadas por ; (ou \n)
  
## Como rodar?
> make //compila os arquivos
-------
> echo "expressao" | ./mybc
